# Code guide: every file and folder, why it exists, what it needs, how it is used

This guide walks through the repository in execution order. For each item: **what** it is, **why** it is needed (which charter/PRD requirement it serves), **needs** (inputs and dependencies), and **use case** (when you touch it).

## `reference/mat_original/`

The authors' original `transformer.py`, `utils.py`, `data_utils.py`, `EXAMPLE.ipynb`, `README.md`, `LICENSE` (MIT). **Why:** the fidelity test imports the original `make_model` and checks that our re-implementation produces identical outputs with identical weights. It is never used for training. **Use case:** `tests/test_mat_fidelity.py`; reading it side by side with `src/molbench/models/mat.py` is the fastest way to verify architectural faithfulness.

## `src/molbench/` (the package)

### `config.py`
**What:** paths (`ROOT`, `DATA_RAW`, `RESULTS_*`), `SEEDS = [42, 123, 456, 789, 1011]`, `N_FOLDS = 5`, `VAL_FRACTION = 0.10`, `MAX_HEAVY_ATOMS = 100`, the task registry (`TASKS`: file, type, label), metric lists, the primary metric per task type, `HIGHER_IS_BETTER`, model registries (`TIER1_MODELS`, `TIER2_MODELS`), display labels, featurisation constants (`D_ATOM = 28`, ECFP 2048 bits, radius 2, conformer seed), and `PRETRAINED_ARCH` (1024 / 8 layers / 16 heads / exp kernel / N_dense 1, verified from the checkpoint).
**Why:** one place for every protocol constant, so that scripts, tests and the report agree.
**Use case:** change a seed list or add a task here and everything follows. `MOLBENCH_ROOT` env var relocates the project.

### `data.py`
**What:** `load_raw`, `largest_fragment`, `clean_dataset` (parse → largest fragment → canonicalise → drop >100 heavy atoms → duplicate/conflict policy → scaffold and heavy-atom columns → log), `bemis_murcko_scaffold`, `random_folds` (StratifiedKFold / KFold), `scaffold_folds` (balanced scaffold K-fold: ring-free molecules are individual groups, groups larger than n/(2k) placed first in seeded random order, greedy smallest-fold assignment), `make_splits` (adds the seeded 10 % validation hold-out), `save/load_splits`, `check_splits` (disjoint, exhaustive, balanced, scaffold-disjoint), `recover_regression_scale` (exact linear map from z-scored to original units), `load_processed`.
**Why:** charter phase II (dataset curation) and the Random vs Scaffold evaluation (objective 5).
**Needs:** RDKit, scikit-learn.
**Use case:** any question about "how were the splits made" is answered here; `tests/test_data_and_metrics.py` covers it.

### `featurize.py`
**What:** `atom_features` (one-hot atomic number [B,C,N,O,F,P,S,Cl,Br,I,other], degree 0–5, H count 0–4, formal charge −1/0/+1, ring, aromatic = 27 dims), `ecfp` (Morgan radius 2, 2048 bits), `embed_conformer` (ETKDGv3 with fixed seed, random-coordinate retry, UFF relaxation, RemoveHs; 2D fallback exactly like the authors), `featurize_mol` (node matrix with dummy-node column, adjacency with self-loops, Euclidean distance matrix, dummy node with 1e6 distances), `featurize_smiles`, on-disk cache (`load_cache`, `save_cache`, `featurize_all` with a multiprocessing pool, largest molecules first), `task_features` (aligns cache records with a processed CSV).
**Why:** charter phase II/III (ETKDG conformers, adjacency and distance matrices), and identical inputs for all graph/geometry models. The featurisation matches the authors' `data_utils.py` line for line so the pretrained weights are valid.
**Use case:** `scripts/01_prepare_data.py`; `tests/test_data_and_metrics.py::test_featurisation_invariants`.

### `metrics.py`
**What:** `classification_metrics` (ROC-AUC, PR-AUC = average precision, F1 at 0.5; NaN when a set has one class), `regression_metrics` (RMSE, MAE, R²), `compute_metrics`.
**Why:** charter success criteria.
**Use case:** engine and tests.

### `models/classical.py`
**What:** `tanimoto_kernel` (Jaccard on binary fingerprints), `fit_predict_rf` (RandomForestClassifier/Regressor, seeded), `fit_predict_svm` (SVC/SVR with `kernel="precomputed"`; classification scores = sigmoid of the decision function so the 0.5 threshold equals the SVM decision boundary).
**Why:** charter objective 1 (tuned RF and SVM/SVR baselines). The Tanimoto kernel is the standard similarity for fingerprints.
**Use case:** `engine.run_classical`.

### `models/gcn.py`
**What:** `GCN` (PyG `GCNConv` stack, ReLU, dropout, mean+max global pooling, two-layer head) and `record_to_pyg` (drops the dummy node, removes self-loops because GCNConv adds its own, builds `edge_index`; single-atom molecules get an empty edge set).
**Why:** charter objective 1 (GCN baseline in PyTorch Geometric).
**Use case:** `engine` GCN path; `tests/test_models.py`.

### `models/mat.py`
**What:** faithful MAT: `LayerNorm` (unbiased std, eps added to std, as in the original), `SublayerConnection` (pre-norm residual), `MultiHeadedAttention` (λ_a · softmax(QKᵀ/√d) + λ_d · g(D) + λ_g · A_norm, distance kernel softmax or exp, padded key masking, `store_attention` capture), `PositionwiseFeedForward`, `EncoderLayer`, `Encoder`, `Embeddings`, `Generator` (masked mean pooling + linear), `GraphTransformer` (`forward`, `encode`, `pool`, `attention_maps`, `lambdas`), `ABLATION_LAMBDAS`, `make_model` (Xavier init like the authors), `make_mat_variant` (MAT or an ablation), `make_pretrained_arch`, `load_pretrained` (copies all non-generator tensors, asserts full encoder coverage).
**Why:** charter objectives 2 (reproduce MAT from scratch), 3 (ablations), 4 (pretrained vs scratch), 7 (attention analysis). Parameter names equal the authors' so the checkpoint loads directly and the fidelity test can compare implementations.
**Use case:** `engine.build_torch_model`; `tests/test_mat_fidelity.py`, `tests/test_models.py`.

### `models/hybrid.py`
**What:** `ECFPMATHybrid`: MAT encoder → masked mean pooling ⊕ ReLU(Linear(2048→128))(ECFP) → one linear output layer (same head depth as MAT, so the comparison isolates the fingerprint input). MAT's unused generator is replaced by `Identity`.
**Why:** charter objective 6 (ECFP-MAT late fusion).
**Use case:** `engine` hybrid path.

### `grids.py`
**What:** hyperparameter grids per family (`rf_grid`, `svm_grid`, `gcn_grid`, `mat_grid`), `INHERITS_MAT` (ablations and hybrid reuse MAT's tuned configuration), `TIER2_CONFIG` (lr 1e-4, batch 32, 15 epochs, patience 5), `TIER2_LOCAL` (seed 42, 8 epochs, patience 3 for the CPU run).
**Why:** PRD 3.2 fairness policy; one place to see every searched value.
**Use case:** `scripts/02_tune.py`, `04_run_tier2.py`.

### `engine.py`
**What:** `seed_everything`, `DEVICE` (CUDA if available or `MOLBENCH_DEVICE`), `MolDataset` + `mol_collate` (pads atom/adjacency/distance matrices per batch, builds the atom mask like the authors' `batch_mask`), `BucketBatchSampler` (seeded "sortish" batching: shuffle, size-sort within chunks, shuffle batch order; halves padding cost on CPU), `make_loader`, `make_pyg_loader`, `build_torch_model` (all deep variants incl. pretrained loading), `forward`, `predict` (sigmoid for classification, inverse standardisation for regression), `run_torch` (Adam, gradient clipping 5.0, early stopping on validation ROC-AUC/RMSE with divergence guard, best-state restoration, val and test metrics, epochs, parameter count, wall time), `run_classical`, `run_one`.
**Why:** one identical training/evaluation procedure for all deep models (fairness), and one identical scoring path for all models.
**Use case:** called by the runner for every job; `tests/test_engine.py`.

### `runner.py`
**What:** `ROW_FIELDS` (CSV schema incl. metrics, validation metrics, epochs, parameters, wall time, configuration JSON, configuration hash, epoch budget, device, torch version, error), `cfg_hash`/`job_hash`/`run_key`, `_init_worker` (per-process feature cache, thread limits via threadpoolctl and torch), `run_job` (executes one job, never crashes the grid: exceptions become an `error` cell), `load_done`, `run_grid` (multiprocessing pool with `imap_unordered`, appends rows as they finish, skips rows already present with the same key and configuration hash).
**Why:** 2800+ runs on 16 cores need parallelism and must survive interruptions.
**Use case:** all run scripts.

### `stats.py`
**What:** `t_ci`, `bootstrap_ci`, `holm`, `summarize` (mean/std/CI per task, split, model, metric), `paired_tests` (paired t-test + Wilcoxon signed-rank), `compare_to_reference` (every model vs a reference on paired (seed, fold) scores, Holm within families, significance flags, direction-aware "reference_better"), `ablation_contributions` (MAT minus ablation), `generalization_gap` (random minus scaffold, Welch CI and test), `average_ranks` (MAT-paper-style), `aggregate_by_seed` (seed-level robustness), `load_runs`.
**Why:** charter success criteria (paired t-tests, Wilcoxon, 95 % CIs, generalization gap, p < 0.05).
**Use case:** `scripts/05_stats.py`; `tests/test_stats.py`.

### `attention.py`
**What:** `atom_classes`, `collect_attention` (runs a trained MAT with capture on, keeps per-layer per-head self-attention and fused attention per molecule), `head_statistics` (bonded share, self share, dummy share, Spearman correlation with inverse distance, entropy per layer/head/kind), `received_by_class` (attention received by aromatic / heteroatom / ring / halogen / aliphatic-carbon / dummy atoms), `baseline_uniform_shares`.
**Why:** charter objective 7 (analyse multi-head attention weights).
**Use case:** `scripts/06_attention.py`.

### `plotting.py`
**What:** fixed per-model colours (identity never cycles; MAT family in blue), performance panels with 95 % CI bars, ablation forest plot, generalization-gap plot, pretrained-vs-scratch bars, average ranks, attention head statistics, attention received by atom class, attention heat-maps with bonds marked.
**Why:** charter tooling (Matplotlib/Seaborn visualisation) and PRD 4.3.
**Use case:** `scripts/07_figures.py`.

## `tests/`

| File | Covers |
|---|---|
| `test_mat_fidelity.py` | Output equality with the authors' `transformer.py` for both distance kernels and four λ settings; complete pretrained checkpoint loading; pretrained forward equality |
| `test_models.py` | λ triplets sum to 1; NoGraph ignores adjacency; NoDistance ignores distances; NoAttention has zero Q/K gradients; full MAT uses all terms; attention rows sum to 1; padding invariance; GCN forward/gradients and single-atom molecules; hybrid forward/gradients |
| `test_data_and_metrics.py` | Cleaning policy; scaffold folds disjoint/exhaustive; acyclic molecules spread across folds; seed dependence; featurisation invariants (shapes, symmetry, dummy node, bond lengths); Tanimoto kernel; metric values |
| `test_engine.py` | Every deep model trains on both task types; regression metrics in label units; RF/SVM paths; same seed → identical result |
| `test_stats.py` | t-CI vs scipy; Holm; summaries, comparisons, ablations, gap, ranks on synthetic runs; identical inputs give p = 1 |

Run with `python -m pytest tests -q` (about 30 s).

## `notebooks/colab_tier2.ipynb`

GPU notebook for the full 5-seed pretrained-vs-scratch protocol: checks the GPU, installs RDKit/PyG, unzips the bundle, installs `molbench`, downloads the checkpoint, runs the fidelity tests, runs `04_run_tier2.py` with `MOLBENCH_DEVICE=cuda`, and downloads `tier2_runs.csv`. No credentials required.
